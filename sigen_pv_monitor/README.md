# Sigen PV Monitor – dodatek Home Assistant

Falownik i magazyn energii Sigenergy (Modbus TCP) w Home Assistant: podgląd na żywo, prognoza PV, ceny energii,
strategia magazynu (z opcjonalnym sterowaniem falownikiem), licznik Pstryk, rekuperator Vallox oraz 9 kart panelu HA.

Instalacja i opis: zakładka **Dokumentacja** dodatku.
